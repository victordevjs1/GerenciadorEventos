RECUPERAÇÃO DE SENHA POR E-MAIL - e-task

1. BANCO DE DADOS
Se você já possui o banco gerenciador_eventos, execute somente:
src/main/java/br/com/gerenciadoreventos/util/migracao_recuperacao_senha.sql

Se for criar o banco do zero, o projeto2.sql já contém a tabela recuperacao_senha.

2. E-MAIL
A funcionalidade usa SMTP SSL e não adiciona biblioteca nova ao projeto.
Por padrão, o servidor é smtp.gmail.com na porta 465.

Configure estas variáveis de ambiente na execução do projeto:
ETASK_SMTP_USER=seuemail@gmail.com
ETASK_SMTP_PASSWORD=sua_senha_de_app

Opcionais:
ETASK_SMTP_HOST=smtp.gmail.com
ETASK_SMTP_PORT=465
ETASK_SMTP_FROM=seuemail@gmail.com

No Gmail, use uma Senha de App; não coloque a senha normal da conta no código-fonte.
No IntelliJ: Run > Edit Configurations > Environment variables.

Também é possível usar propriedades Java equivalentes:
-D etask.smtp.user=...
-D etask.smtp.password=...
-D etask.smtp.host=...
-D etask.smtp.port=465
-D etask.smtp.from=...
(remova o espaço entre -D e o nome ao usar na JVM, por exemplo: -Detask.smtp.user=...)

3. FLUXO
Login > Esqueceu sua senha? > e-mail > código de 6 dígitos > nova senha.
O código expira em 10 minutos e é bloqueado após 5 tentativas incorretas.
Ao solicitar um novo código, o anterior é invalidado.
A nova senha continua sendo salva com BCrypt.
